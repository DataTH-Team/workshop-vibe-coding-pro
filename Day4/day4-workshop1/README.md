# Workshop 4 — Cafe Chatbot (Demo)

หน้าคุยกับ Chatbot สำหรับเจ้าของร้าน Cafe เพื่อถามข้อมูลยอดขาย

## เปิดใช้งาน

**วิธีง่ายสุด:** ดับเบิลคลิก `index.html` เปิดในเบราว์เซอร์ได้เลย (ไม่ต้องรัน server)

ข้อมูลตัวอย่างฝังอยู่ในไฟล์แล้ว ไม่ได้ดึงจากไฟล์อื่น

ถ้าอยากเปิดจากมือถือใน Wi‑Fi เดียวกัน ค่อยใช้ server:

```bash
# ดับเบิลคลิก serve.command
# หรือ
cd workshop4
python3 -m http.server 8080
```

แล้วเปิด `http://localhost:8080` (หรือ IP คอมจากมือถือ)

## คำถามตัวอย่าง

- ยอดขายสัปดาห์ที่แล้วเท่าไหร่?
- เมนูไหนขายดีที่สุด?
- แยกตามหมวดหมู่
- ช่องทางไหนขายดี?
- วันไหนยอดสูงสุด?
- เมื่อวานขายได้เท่าไหร่?

## หมายเหตุ

- ใช้**ข้อมูลตัวอย่าง**และ**คำตอบสำเร็จรูป** (จับคีย์เวิร์ด)
- ยัง**ไม่มี Backend** หรือเชื่อมต่อ API จริง
- เวอร์ชันถัดไปสามารถต่อ CSV / Google Sheets / LLM API ได้
