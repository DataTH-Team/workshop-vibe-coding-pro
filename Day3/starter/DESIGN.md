## กฎที่ห้ามพลาด

- **อย่าใส่เมนูหรือปุ่มที่กดแล้วไม่มีอะไรเกิดขึ้น** — ทุกอย่างใน sidebar ต้องส่งค่าเข้า query จริง
  ถ้าจะมีตัวกรอง ต้องต่อเข้า `WHERE` ของทุกคิวรีบนหน้านั้น
- **อย่าใส่ตัวเลขเปรียบเทียบที่ไม่มีข้อมูลรองรับ** เช่น `↑42% จากปีที่แล้ว`
  ถ้า dataset ไม่มีปีก่อน ให้ใส่บรรทัดอธิบายนิยามแทน
- ปุ่มต้องถูกทาสีเอง — Streamlit default เป็นเทาเข้ม ไม่เข้าธีม
  ```
  .stButton>button{border-radius:999px;background:#fff;color:#45115d;border:1px solid #eadfec}
  .stButton>button[kind="primary"]{background:#df3141;color:#fff;border:0}
  ```
- `div[role="radiogroup"] label` ทำเป็นชิปแคปซูล ไม่งั้นได้วงกลมเริ่มต้นของ Streamlit
- **ห้ามใช้ `st.selectbox` ใน sidebar พื้นเข้ม** — เรนเดอร์เป็นกล่องขาวเปล่า
  ไม่มีข้อความข้างใน (ตรวจจาก DOM จริงแล้ว) ใช้ `st.radio` แทน
- **ลูกศร/ปุ่มบนการ์ดต้องเป็น `<a href>` จริง** อย่าใส่ `<span>` เปล่าเพราะลอกจาก mockup
- ต้องมี `.streamlit/config.toml` ปักธีมสว่าง ไม่งั้น dark mode จะอ่านไม่ออก
  ```toml
  [theme]
  base = "light"
  primaryColor = "#45115d"
  backgroundColor = "#fbf8f3"
  textColor = "#24162d"
  ```
- บล็อกสไตล์ที่ส่งผ่าน `st.markdown` **ต้องเป็นบรรทัดเดียว**
  ถ้ามีบรรทัดว่างคั่น Streamlit จะโชว์ CSS เป็นข้อความบนหน้าเว็บ
- กราฟ plotly ต้องตั้ง `template="plotly_white"` ไม่งั้นตัวหนังสือจมพื้น
- ในสไลด์และแอปห้ามเขียนคำโปรยที่เล่าคอร์ส ("เว็บที่ทำเมื่อวันแรก")
  คนเปิดเว็บจริงไม่ได้อยู่ในคลาส

## ไฟล์ที่แจกมาให้ ห้ามสร้างเอง

| ไฟล์ | ใช้ทำอะไร |
