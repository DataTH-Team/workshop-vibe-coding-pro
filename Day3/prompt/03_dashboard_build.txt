--- ก้อน B  วางใน Genie Code  (ขั้นที่ 3) ---

จาก dataset bookings ทำ 4 อันนี้บนหน้าเดียว เอาเฉพาะปี 2025

- ตัวเลขรายได้รวม นับเฉพาะ confirmed กับ completed
- ตัวเลขจำนวนการจองทั้งหมด
- ตัวเลขอัตราการยกเลิก คือ cancelled หารด้วยการจองทั้งหมด
- กราฟเส้น รายได้รายเดือน

สำคัญ ให้กรองปีและคำนวณทุกอย่างใน SQL ของ dataset
อย่าไปกรองหรือคำนวณหรือปัดทศนิยมในตัว widget
สร้าง dataset สรุปเพิ่มได้ ไม่ต้องกลัวว่าจะมีหลายอัน

ต้องได้  รายได้ 11,140,266 . จอง 57,816 . ยกเลิก 21.5%
กราฟเส้นมี 7 จุด (ม.ค.-ก.ค.) ถูกแล้ว ข้อมูลมีถึงแค่ ก.ค. 2025
ถึงตรงนี้ Publish ได้เลย ถือว่าผ่าน Workshop 1


--- ก้อน C  ทำให้หน้าเต็ม  (ขั้นที่ 4) ---

ทำให้หน้านี้ดูเต็มขึ้นอีก 3 อัน

กติกา ทุกอันให้สร้าง dataset ใหม่แยกของตัวเอง
สรุป เรียง และตัดจำนวนแถวให้เสร็จใน SQL
ตัว widget มีหน้าที่แค่วาด
ห้ามใส่ sort limit categorySize หรือ format ใน widget

1 กราฟแท่งแนวนอน 10 เมืองที่รายได้สูงสุด
2 ตารางรายเมือง มีเมือง จำนวนการจอง รายได้ อัตราการยกเลิก
3 กราฟโดนัท สัดส่วนสถานะการจอง

ทุก dataset เอาเฉพาะ check_in ปี 2025
รายได้นับเฉพาะ confirmed กับ completed

ชื่อเมืองไม่ได้อยู่ในตาราง bookings ต้องต่อ 2 ทอด
bookings.property_id = properties.property_id
properties.destination_id = destinations.destination_id
คอลัมน์ชื่อเมืองคือ destination ไม่ใช่ city

ต้องได้  Phuket 1,156,263 . Gold Coast 1,039,577 . Mallorca 1,014,619
โดนัท  pending 43.6% . confirmed 24.6% . cancelled 21.5% . completed 10.2%


--- ถ้าพัง วางต่อทีละบรรทัด ---

เอาการคำนวณไปไว้ใน SQL ของ dataset อย่าคำนวณใน widget
ปัดทศนิยมด้วย ROUND ใน SQL อย่าใส่ format ใน widget
เรียงและตัด 10 อันดับด้วย ORDER BY กับ LIMIT ใน SQL
ถ้ายังพัง ลบ widget นั้นทิ้ง แล้วสร้าง dataset ใหม่ที่สรุปมาแล้ว


หลักการเดียวที่ต้องจำ
งานคำนวณ เรียง และตัดแถว อยู่ใน SQL ของ dataset
widget มีหน้าที่แค่ชี้ว่าจะเอาคอลัมน์ไหนมาวาด
error ว่า must be object / must have required property / must be equal to
แปลว่ามันไปทำงานในตัว widget ให้ไล่กลับไปทำใน SQL
