## Prompts

### Workshop 1
ตัวอย่าง Prompt:
```
ฉันเป็นเจ้าของร้าน Cafe ช่วยสร้างหน้าเว็บสรุปยอดขายสัปดาห์ที่แล้ว อยากรู้ว่าเมนูไหนขายดีบ้าง

สรุปข้อมูลดูง่าย ๆ เปิดจากมือถือได้

ข้อมูลอยู่ที่ orders.csv
```

ไอเดียการปรับแต่ง:
- ขอเว็บมินิมัล โทนสีขาว-แดงเข้ม
- ขอฟ้อนต์ไทยสวย ๆ
- ขอหน้าตาแบบเว็บ abc.com
- เพิ่ม Pie Chart แบ่งตามประเภทสินค้าให้หน่อย
- ขอเลขข้อมูลสำคัญแบบชัด ๆ: ยอดขายรวม, จำนวนแก้ว, ยอดเฉลี่ยต่อบิล

### Workshop 2.1
ตัวอย่าง Prompt:
```
ฉันเป็นเจ้าของร้าน Cafe อยากได้ Dashboard แสดงว่าสินค้าไหนขายดี กลุ่มไหนขายดี เลือกช่วงเวลาที่ต้องการดูได้

ดึงข้อมูลแบบเชื่อมต่อจาก Google Sheets โดยตรง:
<url>
```

ไอเดียการปรับแต่ง:
- ขอ Dark Mode แบบมีตัวสลับ Light-Dark Mode
- ทำให้กราฟมีสีสันขึ้นหน่อย
- ด้านบนสุด เขียนสรุป Trend วันนี้ให้หน่อย

ตัวอย่างคำถาม:
- ถ้าอยากให้สรุปยอดขายส่งเข้าไลน์ทุกวัน ทำยังไง
- อยากแชร์ Dashboard นี้ให้เพื่อน ทำยังไง
- ทำนายยอดขายในอนาคตได้มั้ย

### Workshop 3
ตัวอย่าง Prompt:
```
ฉันเป็นเจ้าของร้าน Cafe อยากได้เว็บมือถือ 2 หน้า: หน้าลูกค้าสั่งกาแฟล่วงหน้า และหน้าพนักงานรับออเดอร์พร้อมเปลี่ยนสถานะ
หน้าเว็บขอเป็น HTML/CSS/JS ปกติ ไม่ใส่หน้าเว็บใน Apps Script และไม่ใช้ Node.js

ใช้ Google Apps Script ใน Google Sheets นี้เป็นฐานข้อมูล: <URL Google Sheets>
```

ไอเดียการปรับแต่ง:
- หน้าจอสั่งอาหาร: อยากให้เวลาสั่งกาแฟ เลือกได้ด้วยว่าจะใส่กาแฟกี่ชอต (Half shot, Default, Extra Shot)
- หน้าจอสั่งอาหาร: ถ้าสั่ง Butter Croissant ขึ้นบอกลูกค้าว่า ตอนนี้มีโปร 1 แถม 1

และในช่อง Quantity ให้เลือกได้เฉพาะเลขคู่
- หน้าจอของพนักงาน: ถ้าลูกค้าสั่งเมนูเดียวกัน เอามาเรียงกันให้หน่อย จะได้ทำทีเดียว
