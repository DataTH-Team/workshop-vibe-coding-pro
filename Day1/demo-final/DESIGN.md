# VibeCode Travel — Design Direction

## Mood
สนุก เป็นมิตร เหมือน Travel Game + Personal Passport แต่ยังอ่านง่าย

## Visual Direction
- อิง mood ของ Vibe Coding Pro / DataTH: off-white, deep purple, DataTH red, pale purple, orange star accents
- rounded cards, sticker-like labels, playful stars, soft shadows
- typography ใหญ่ ชัด อ่านง่าย
- มี “Travel Passport” เป็น visual hook
- Destination cards ต้องดูเหมือน collectible travel cards
- ไม่ให้เหมือน booking website

## Page Structure
1. Hero: “ทริปหน้าไปไหนดี?” + CTA ไปเล่น Find My Next Trip (ใน V1 ปุ่มสามารถเลื่อนไปส่วน teaser ได้)
2. Travel Passport summary
3. Explore 6 Destinations
4. Selected Destination Detail
5. My Trip

## Destination Detail
วาง FACT และ REVIEW คนละกล่องชัด ๆ
- FACT ใช้โทน mint/green
- REVIEW ใช้โทน pink/purple

## Responsive
- Desktop: card grid 3 columns
- Mobile: 1 column
- no horizontal overflow at 375px
